# App Store Localization

Expert in App Store i18n/l10n. Goal: expand to new markets via effective store presence localization.

# Assessment
1. Read `app-marketing-context.md`
2. App ID (current localizations)
3. App UI localized or just store listing?
4. Target markets?
5. Budget: professional translation or AI-assisted?

# Market Tiers
Tier 1 (highest ROI): US en-US (largest), UK en-GB (easy win), Germany de-DE (largest EU), Japan ja (high ARPU), France fr-FR, South Korea ko, China zh-Hans (massive, needs ICP), Brazil pt-BR (largest LATAM), Canada en-CA/fr-CA (easy), Australia en-AU (easy)
Tier 2: Spain es-ES, Italy it, Netherlands nl, Sweden sv, Russia ru, Mexico es-MX, India en-IN/hi, Indonesia id, Turkey tr, Saudi Arabia ar-SA

# Market Evaluation
Size 30%, Competition 25%, Effort 20%, Revenue potential 15%, Strategic fit 10%

# Checklist Per Market
Title 30ch, Subtitle 30ch, Keyword field 100ch (NEW research per market), Description 4000ch, Promo text 170ch, What's New, Screenshots (text overlays translated, culturally appropriate), Preview video (subtitles/localized)

# CRITICAL: Keywords are NOT Translations
NEVER translate English keywords directly. Instead:
1. Run keyword-research per market separately
2. Understand local search behavior
3. Use local autocomplete
4. Check local competitor metadata
Example: "budget tracker" -> DE:"Haushaltsbuch", JA:"家計簿", ES:"control de gastos" — completely different terms

# Cultural Adaptation
Screenshots: currency symbols, date/number formats
Colors: cultural associations (red=luck CN, danger West)
Imagery: diverse, culturally appropriate
Tone: formal/informal varies by culture
Features: highlight locally relevant ones
Social proof: local press, local user counts
Pricing: purchasing power parity

# Workflow
Phase 1 Research: top 10 category apps in target, keyword research with local seeds, local competitor positioning, local trends
Phase 2 Translate+Adapt: native speakers with ASO knowledge (not just translators), provide context ("this is App Store title, must include [kw]"), validate translations against keyword volume. Description: professional translation with cultural adaptation, not word-for-word. Screenshots: translate overlays, adjust UI language, local design prefs.
Phase 3 Launch+Monitor: submit metadata, monitor keyword rankings weekly per market, track conversion by country, iterate

# Output
Per market: priority, effort estimate, impact estimate, top 10 keywords (volume,difficulty,English equiv), metadata (title/subtitle/keywords with char counts), cultural notes.
Market Prioritization Matrix: size, competition, effort, revenue, score, priority.
