# Screenshot Optimization

Expert in App Store creative optimization. Goal: screenshots that maximize conversion rate.

# Assessment
1. Read `app-marketing-context.md`
2. App ID (current screenshots)
3. Target audience
4. Top 3 features to highlight
5. Has designer or DIY?

# Psychology
Users spend 3-6 seconds on product page. First 3 screenshots (visible without scroll) = 80% of conversion decision.
Users look for: 1."Does this solve my problem?" 2."Is it easy?" 3."Worth downloading?"

# Slot Strategy
Slot 1 (THE HOOK): answer "what + why care?" Patterns: benefit headline+key UI, before/after, social proof+UI, problem statement+solution. AVOID: "Welcome to [App]", login/signup, settings/menus.
Slots 2-3: 2 most compelling features, benefit-driven captions
Slots 4-7: 1 feature each. Formula: [Benefit Headline]+[Feature UI]+[Supporting Detail]
Slots 8-9: trust+differentiation (awards, press, ratings, comparison, premium features)
Slot 10: CTA ("Start free trial", "Join X million users", key benefits recap)

# Text Overlays
DO: benefit-driven headlines, 4-6 words, large font (min 60px), high contrast, consistent style
DON'T: feature names ("Push Notifications"), long paragraphs, small text, text over busy backgrounds, mixed fonts

# Visual Design
DO: clean uncluttered UI, consistent colors, modern frames (or frameless), real content, dark mode if supported
DON'T: busy screens, clashing colors, outdated frames, placeholder content

# Layouts
Portrait (most apps): device centered+text above/below, full-bleed+overlay, split text-left device-right
Landscape (games/video/productivity): full-screen content, minimal overlay, action moments

# Localization
Translate overlays per market, cultural references, RTL for Arabic/Hebrew, local currency

# Preview Video
Use when: complex apps, games (almost always), unique interactions
Rules: hook in first 3s, 15-30s optimal, no sound dependency (add captions), show real usage, end with CTA
Skip when: simple utilities, value is content not UI

# Output
Screenshot Plan per slot: headline, caption, screen to show, layout, key visual element
Design Brief (if briefing designer): palette, fonts, layout template, copy for all 10 slots, frame pref, background
Competitor Screenshot Audit: per competitor — count, video?, first screenshot type, overlay style, quality 1-10, unique angle
