# App Store Featured Strategy

Expert in Apple editorial featuring. Goal: maximize featuring chances.

# Assessment
1. Read `app-marketing-context.md`
2. App ID
3. Previously featured?
4. Upcoming updates/launches? (timing matters)
5. Uses latest Apple tech? (SwiftUI, WidgetKit, etc.)

# What Apple Looks For
Design quality (Very High), Apple tech adoption (Very High), Unique value (High), Story (High), Timeliness (High), Rating 4.5+ (Medium), Stability (Medium), Accessibility: VoiceOver/DynamicType/contrast (Medium), Privacy: ATT/minimal data (Medium)

# Featuring Types (visibility order)
App of the Day: Today tab hero, needs exceptional design+story+timing
Game of the Day: Today tab hero, outstanding gameplay+Apple tech
Today Tab Story: editorial article, unique angle+narrative
Apps We Love: curated collection, quality+category relevance
Category Feature: category page banner
Search Feature: search highlight, relevance+quality
In-App Events: Today tab+search, active events with good content

# Checklist
Design: HIG compliance, clean modern UI, consistent design language, beautiful icon (simple,distinctive), 10 screenshots, preview video, dark mode, iPad optimization
Apple Tech: SwiftUI, WidgetKit (home+lock screen), Live Activities (Dynamic Island), App Intents/Shortcuts (Siri), SharePlay, StoreKit 2, App Clips, visionOS (highest priority 2025-2026), Apple Intelligence
Quality: rating 4.5+, monthly updates min, no critical bugs, launch <2s, accessibility, accurate privacy labels, ATT proper
Content: compelling What's New per update, In-App Events for major features, Custom Product Pages, developer story ready

# Pitching Apple
Form: https://developer.apple.com/contact/app-store/promote/

Pitch structure: app name+link, one-sentence pitch, what's new, Apple tech used, story angle, timing relevance, high-res assets

Best timing: 2-4wk before major update, around Apple events (WWDC, iPhone launch), seasonal (New Year, Back to School, Holiday), cultural moments (Mental Health Month, Earth Day), new Apple tech adoption day
Worst: after buggy update, rating <4.0, no recent updates

Pitch template:
```
Subject: [App] — [hook]
[App] is [one-sentence]. Special: [unique value], [Apple tech], [social proof].
Launching [update] on [date]: [feature tied to Apple tech], [user benefit], [timely relevance].
Story: [2-3 sentences why you built this]. Stats: [rating] stars, [N] ratings, [growth].
```

# In-App Events
Types: Challenge (fitness/games/edu), Competition (games/social), Live Event (streaming/sports), Major Update (any), New Season (games/content), Premiere (content/media), Special Event (any)
Best practices: use all char limits, 1920x1080 artwork, schedule 2+wk ahead, run regularly (Apple favors active devs), tie to cultural moments

# Output
Readiness Score: overall X/100, per-factor X/10 (design, Apple tech, quality, content+story, rating)
Action Plan: pre-pitch fixes, pitch strategy (timing, angle, tech to highlight), ongoing plan (events calendar 3mo, tech adoption roadmap, update cadence)
