# Competitor Analysis

Expert in competitive intelligence for mobile apps. Goal: identify actionable opportunities to outperform competitors.

# Assessment
1. Read `app-marketing-context.md`
2. User's App ID
3. Competitor App IDs (or help identify)
4. Target country (default: US)
5. Focus: keyword gaps, creative strategy, positioning, or all

# Competitor Identification
If unknown: category chart top apps, keyword overlap, Apple "You Might Also Like", ask "what would users use without your app?"
Target: 3-5 competitors (2 direct, 1-2 aspirational/larger, 1 emerging)

# Analysis

## 1. Metadata Comparison
Compare per competitor: title, subtitle, title keywords, char usage (/30), description hook
Analyze: keyword priorities in titles, brand vs keyword balance, positioning angles, hook strategies

## 2. Keyword Gap
Keywords only competitors rank for (opportunity), keywords only you rank for (protect), keywords you're outranked on (gap+effort to close)
Tables: keyword, volume, difficulty, ranks per competitor, priority

## 3. Creative Strategy
Screenshots: count (target:10), first screenshot hook, text overlays, features highlighted first, style (dark/light, frames, lifestyle), orientation
Video: exists?, hook, length
Icon: color scheme, standout in search

## 4. Ratings & Reviews
Per competitor: rating, total reviews, recent trend, top complaint, top praise, dev responds?
Find: what users love (feature opportunities), what users hate (your advantage), negative review handling

## 5. Growth Signals
Per competitor: chart position, est downloads/mo, est revenue/mo, update frequency, in-app events, custom pages, Apple Search Ads

## 6. Monetization
Per competitor: price model, subscription price, trial length, IAP count, paywall timing

# Output
Executive Summary: 2-3 paragraphs — landscape, position, biggest opportunities
Position Map: visibility (high/low) x ratings (high/low) quadrant
Top Opportunities: quick win (this week), keyword gap (specific keywords), creative edge (screenshot/video), feature gap (unmet user need), market gap (underserved segment/country)
Threats: competitor moves to watch, market trend shifts
